Terminology

Flex Container
An element becomes a flex container when its display value is set to flex or inline-flex.
Flex Items
The direct children of a flex container are flex items that participate in the flex layout.
Flex Directions
Flex direction determines whether the main axis runs as a row or column and whether its order is reversed.
Main axis
The main axis follows the selected flex direction and is the axis along which flex items are placed.
Main size properties
The width or height property that corresponds to the main axis, depending on the flex direction.
Cross axis
The cross axis runs perpendicular to the main axis and controls cross-axis alignment.
Cross size properties
The width or height property that corresponds to the cross axis, depending on the flex direction.

Properties

Flex Container Properties

display
flex; /* creates a block-level flex container */ inline-flex; /* creates an inline-level flex container */
flex-direction
row; /* displays items horizontally */ row-reverse; /* opposite of row */ column; /* displays items vertically */ column-reverse; /* displays a vertical row in reverse */
flex-wrap
nowrap; /* flex item will not wrap */ wrap; /* flex items wrap if necessary */ wrap-reverse; /* items wrap in reverse order */
flex-flow
row nowrap; /* combines direction and wrapping in one declaration */ column wrap; /* creates wrapping vertical columns */
justify-content
flex-start; /* items are aligned at the beginning of the container */ flex-end; /* items are aligned at the end of the container */ center; /* centers items on the main axis */ space-between; /* puts equal space between items */
align-items
stretch; /* stretches items across the cross axis */ center; /* centers items on the cross axis */ flex-start; /* aligns items to the cross start */
align-content
stretch; /* stretches wrapped lines across available space */ space-between; /* distributes space between wrapped lines */ center; /* centers wrapped lines on the cross axis */

Flex Item Properties

order
number; /* specifies the order with a default value of 0 */ initial; /* sets the order to 0 */ inherit; /* the same order value as the parent item */
flex-grow
number; /* specifies how much the item will grow */ initial; /* the default value */
flex-shrink
number; /* specifies how much the item will shrink */ initial; /* the default value */
flex-basis
auto; /* uses the item's width or height as its initial size */ 12rem; /* starts the item at a specific size */
align-self
center; /* Put the item around the center */ flex-start; /* Put the item at the start */
flex
1 1 auto; /* lets an item grow and shrink from its automatic size */ 0 0 12rem; /* keeps an item at a fixed flex basis */
