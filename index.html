My Learning

Three ideas were especially useful in this lesson. First, a flex container controls its children along a main axis and a cross axis, which makes layouts easier to reason about. Second, properties such as justify-content, align-items, and gap can replace fragile spacing techniques. Third, wrapping and flexible basis values allow components to reflow when the viewport narrows or the page is highly zoomed. I can use these techniques for navigation, card collections, dashboards, and accessible responsive layouts.

My Next Steps

I want to explore how flex growth, shrinkage, and basis interact when several items compete for limited space. I will learn more by building layouts with different content lengths, testing them at multiple viewport widths and zoom levels, and comparing the results in browser developer tools.
